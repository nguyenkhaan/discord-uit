Gateway không sở hữu business state

React kết nối Socket.IO tới TypeScript gateway. Gateway xác minh JWT bằng public key, gọi internal REST tới Spring Boot để kiểm tra session, membership và chuyển command. Spring Boot ghi dữ liệu cùng outbox trong PostgreSQL, publish event qua Kafka; gateway consume event và broadcast lại cho React.

Luồng chat-send

Một command, hai đường phản hồi

ACK trả nhanh cho người gửi; Kafka event phát bản ghi đã persist cho toàn bộ thành viên.

  1. Connect và xác thực

    Client gửi JWT; gateway verify public key rồi hỏi Spring xác nhận session/account còn hiệu lực.

  2. Authorize room

    Gateway chỉ join server:{serverId} sau khi Spring xác nhận active membership.

  3. Forward command

    chat-send được chuyển qua internal REST; Spring kiểm tra quyền lần cuối.

  4. Commit atomically

    Spring ghi chat_message và outbox_event trong cùng transaction rồi trả ACK.

  5. Publish và fan-out

    Outbox publisher đẩy chat-created lên Kafka; gateway consume và emit tới room.

01 / Security

Public key chỉ để verify

Private key chỉ tồn tại ở Spring Boot. Gateway không thể tự phát hành access token hợp lệ.

02 / Consistency

Event chỉ xuất hiện sau commit

Transactional outbox loại bỏ việc broadcast dữ liệu chưa lưu hoặc làm mất event khi gateway tạm dừng.

03 / Recovery

REST sửa khoảng trống realtime

Socket.IO giúp cập nhật nhanh; REST history/cursor vẫn là cơ chế tải lại sau reconnect và phục hồi event bỏ lỡ.
