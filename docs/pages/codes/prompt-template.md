Convert `[IMAGE_PATH]` into responsive HTML/CSS pages.

Read and follow:
- `.agents/skills/converting-screenshots-to-html/SKILL.md`
- `docs/pages/codes/rule.md`

Requirements:
- Identify each page in the image.
- Extract and enhance only genuine image assets; preserve real signs and logos inside photographs.

- Build real edge-to-edge full-screen pages with no outer frame or page margin.
- Support and verify desktop, tablet, and mobile.

Save HTML/CSS to `[CODE_OUTPUT_PATH]` and images to `[IMAGE_OUTPUT_PATH]`.
